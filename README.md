## Live site

**[ian-tc-yang.github.io](https://ian-tc-yang.github.io)**

## What the portfolio highlights

- Agentic AI for CAD and industrial design
- Computer vision and computational photography projects
- World-champion autonomous robotics work
- Research experience, publications, technical skills, and leadership
- Direct links to [GitHub](https://github.com/Ian-tc-Yang), [LinkedIn](https://www.linkedin.com/in/ian--yang/), and a downloadable résumé

## Local development

```bash
npm install
npm run dev
```

## Production builds

```bash
# Cloudflare/OpenAI Sites build
npm run build

# Static export used by GitHub Pages
npm run build:pages
```

The `main` branch publishes automatically through GitHub Actions.
